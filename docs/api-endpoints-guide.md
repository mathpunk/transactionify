# API Endpoints

## Create Account

**Endpoint:** `POST /api/v1/accounts`

## Create Payment

**Endpoint:** `POST /api/v1/accounts/{account_id}/payments`

## Get Balance

**Endpoint:** `GET /api/v1/accounts/{account_id}/balance`

## List Transactions

**Endpoint:** `GET /api/v1/accounts/{account_id}/transactions`
